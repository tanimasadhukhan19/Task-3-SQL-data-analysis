# Task 3: SQL for Data Analysis

## Title

**SQL for Data Analysis using Ecommerce Database**

## Objective

The objective of this task is to use SQL queries to extract, manipulate, and analyze structured ecommerce data from a relational database.

## Tools Used

* Programiz Online SQL Compiler
* SQLite
* GitHub
* Notepad

## Dataset

A sample Ecommerce dataset was created for this task.

The database contains three tables:

1. **Customers** – stores customer information.
2. **Products** – stores product information.
3. **Orders** – stores order information.

## Database Tables

### Customers Table

Contains:

* Customer ID
* Customer Name
* City

### Products Table

Contains:

* Product ID
* Product Name
* Category
* Price

### Orders Table

Contains:

* Order ID
* Customer ID
* Product ID
* Quantity

## Queries Performed

### 1. SELECT

Displayed all customer records from the Customers table.

### 2. WHERE

Filtered customers based on their city and displayed customers from Kolkata.

### 3. ORDER BY

Sorted products according to their price in descending order.

### 4. GROUP BY

Counted the total number of orders placed by each customer.

### 5. Aggregate Functions

Used `SUM()` and `AVG()` to calculate the total and average product prices.

### 6. INNER JOIN

Combined information from Customers, Products, and Orders tables.

### 7. LEFT JOIN

Displayed all customers along with their corresponding orders.

### 8. Subquery

Found products whose price was greater than the average product price.

### 9. Product Revenue Analysis

Calculated revenue generated by each product using:

**Revenue = Quantity × Product Price**

### 10. Customer Revenue Analysis

Calculated the total revenue generated by each customer.

### 11. View

Created a `customer_revenue` view to display customer-wise revenue.

### 12. Index

Created an index on the `customer_id` column of the Orders table to improve query performance.
